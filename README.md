Para compilar, abrir la carpeta contenedora en la terminal, ejecutar make y luego escribir lo siguiente:
./programa -i imagen_entrada.pgm -s imagen_salida1.pgm -p imagen_salida2.pgm
Donde los nombres pgm son definidos por el usuario. Además, las imagenes de salidas corresponden a los resultados del algoritmo SIMD y SSE respectivamente
Para eliminar los archivos generados, ejecutar make clean.
